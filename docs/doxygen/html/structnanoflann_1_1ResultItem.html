Detailed Description

template<typename IndexType = size_t, typename DistanceType = double>
struct nanoflann::ResultItem< IndexType, DistanceType >

Each result element in RadiusResultSet.

Note that distances and indices are named first and second to keep backward-compatibility with the std::pair<> type used in the past. In contrast, this structure is ensured to be std::is_standard_layout so it can be used in wrappers to other languages. See: https://github.com/jlblancoc/nanoflann/issues/166
