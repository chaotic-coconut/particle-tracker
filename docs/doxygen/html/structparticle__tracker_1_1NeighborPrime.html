Detailed Description

template<typename DataType>
struct particle_tracker::NeighborPrime< DataType >

A "secondary neighbor" (neighbor of a primary neighbor).

Template Parameters
DataTypenumeric type.

Fields:

  • ind_prime: index of the secondary grid node.
  • dist_prime: array [d, ddx, ddy] returned by GCD_deriv(primary, secondary).
    • dist_prime[0] = d : great-circle distance
    • dist_prime[1] = ddx : partial derivative of distance w.r.t. x-like coordinate
    • dist_prime[2] = ddy : partial derivative of distance w.r.t. y-like coordinate
  • weight_prime: Gaussian weight exp(-(d*d)/shape) based on dist_prime[0].
