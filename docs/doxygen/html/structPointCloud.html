Detailed Description

template<typename DataType>
struct PointCloud< DataType >

Minimal dataset adaptor for nanoflann storing (lon, lat) in a flat array.

Template Parameters
DataTypenumeric type (float/double).

Points are stored as:

pts = [lon0, lat0, lon1, lat1, ..., lon(N-1), lat(N-1)]
