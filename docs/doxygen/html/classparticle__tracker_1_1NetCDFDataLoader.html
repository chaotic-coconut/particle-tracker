Detailed Description

template<typename DataType, typename TimeType = double>
class particle_tracker::NetCDFDataLoader< DataType, TimeType >

Load one or more NetCDF files and store selected variables keyed by time.

Template Parameters
DataTypenumeric output type (float/double recommended)
TimeTypetime type (double by default; often integer seconds are stored after quantization)

Data are stored as: data_[var_name][time_value] -> std::vector<DataType>

Each vector contains the flattened variable slice for that time.

Error policy

  • Per-variable failures do not abort loadData(): they warn (optional) and continue.
  • Accessors throw if requested data were not loaded.
  • In strict mode (PARTICLE_TRACKER_NCDF_STRICT=1), certain structural issues throw.
