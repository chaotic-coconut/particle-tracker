Detailed Description

template<typename DataType, typename TimeType = double>
class NeighborsData< DataType, TimeType >

Spatial neighbor query + Gaussian weighting + multi-variable interpolation.

Template Parameters
DataTypenumeric type.
TimeTypetime type.

This class holds references to:

  • a pre-built KDTree
  • grid longitudes and latitudes (xx_sparse, yy_sparse) and parameters:
  • rad2 : squared KD-tree search radius (approximate metric)
  • shape : Gaussian length scale for weights in terms of great-circle distance

Dateline policy

  • Query longitude is wrapped into (-pi, pi] before search.
  • Grid longitudes are wrapped before calling GCD() to avoid discontinuities if your GCD() implementation expects normalized longitudes.

Compute neighbor list around query point (x,y).

  • Uses KD-tree radius search with rad2 (approx metric).
  • Computes true great-circle distance via GCD for each candidate.
  • Computes Gaussian weights from true distance.
