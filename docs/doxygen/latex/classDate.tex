\doxysubsection{Detailed Description}
Represents a calendar date (day/\+month/\+year) in the Gregorian calendar. 

This is intentionally minimal:\+
\begin{DoxyItemize}
\item No time-\/of-\/day.
\item No timezone or locale.
\end{DoxyItemize}

Arithmetic:\+
\begin{DoxyItemize}
\item increment()/\+decrement():\+ +/\+-\/ 1 day with proper month/\+year rollover.
\item add\+Days(delta):\+ returns a new \doxylink{classDate}{Date} shifted by delta days (uses repeated +/\+-\/1 steps). For large deltas you could add an optimized version, but in your simulation the heavy operations are typically in seconds\+Since() /\+ \doxylink{classDate_a2600e46a280d66a692f6e78fecb6207f}{days\+Since()}, which are O(1).
\item add\+Months(delta):\+ shifts month, clamps day to last valid day of target month.
\end{DoxyItemize}

Comparison:\+
\begin{DoxyItemize}
\item Lexicographic by (year, month, day).
\end{DoxyItemize}

Safety:\+
\begin{DoxyItemize}
\item Constructor validates month/\+day ranges and throws if invalid. 
\end{DoxyItemize}
