\item It is a cheap local approximation used {\itshape only} for KD-\/tree pruning:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{d\string^2\ \string~=\ (dlat)\string^2\ +\ (cos(lat\_avg)\ *\ dlon\_wrapped)\string^2}

\end{DoxyCode}

\item After KD-\/tree returns candidate neighbors, {\bfseries{true}} great-\/circle distance is computed via {\ttfamily \doxylink{geography__utils_8hpp_abea7847440ba0c60abea144b827f95c9}{GCD()}} /\+ {\ttfamily \doxylink{geography__utils_8hpp_abaad9f894463984f3aad42e60f563172}{GCD\+\_\+deriv()}} and used to compute weights.
