\doxysubsection{Detailed Description}
Time and spherical (lon/\+lat) interpolation utilities, including an experimental "{}neighbors-\/of-\/neighbors"{} spatial derivative estimator. 

\hypertarget{interpolation__utils_8hpp_autotoc_md11}{}\doxysubsubsection{\texorpdfstring{What this header provides}{What this header provides}}\label{interpolation__utils_8hpp_autotoc_md11}

\begin{DoxyItemize}
\item {\bfseries{Time interpolation}} of scalar fields using a cubic B-\/spline (Boost).
\item {\bfseries{Spatial neighbor queries}} on a sphere (lon/\+lat) via a KD-\/tree (nanoflann) using a fast approximate metric suitable for KD-\/tree pruning.
\item {\bfseries{Spatial interpolation}} using Gaussian weights derived from {\itshape true} great-\/circle distance.
\item {\bfseries{Experimental}} spatial derivative estimation using a two-\/level neighborhood ("{}neighbors of neighbors"{}) and distance-\/derivative information.
\end{DoxyItemize}\hypertarget{interpolation__utils_8hpp_autotoc_md12}{}\doxysubsubsection{\texorpdfstring{Coordinate conventions}{Coordinate conventions}}\label{interpolation__utils_8hpp_autotoc_md12}
