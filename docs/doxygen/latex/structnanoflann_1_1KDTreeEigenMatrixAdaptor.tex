\doxysubsection{Detailed Description}
\subsubsection*{template$<$class Matrix\+Type, int32\+\_\+t DIM = -\/1, class Distance = nanoflann::\+metric\+\_\+\+L2, bool row\+\_\+major = true$>$\newline
struct nanoflann::\+\+KDTree\+Eigen\+Matrix\+Adaptor$<$ Matrix\+Type, DIM, Distance, row\+\_\+major $>$}
An L2-\/metric KD-\/tree adaptor for working with data directly stored in an Eigen Matrix, without duplicating the data storage. 

You can select whether a row or column in the matrix represents a point in the state space.

Example of usage:\+
