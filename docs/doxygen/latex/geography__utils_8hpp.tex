\doxysubsection{Detailed Description}
Small geographic utilities for spherical (lon/\+lat) computations in radians. 

This header provides:\+
\begin{DoxyItemize}
\item A generic clamp helper.
\item Great-\/circle distance (central angle) on a sphere.
\item Great-\/circle distance and partial derivatives w.\+r.\+t. the {\itshape first} point.
\item A simple "{}inverse transform"{} that applies a local tangent-\/plane offset (x,y in meters) to a reference lon/\+lat and returns the new lon/\+lat.
\end{DoxyItemize}\hypertarget{geography__utils_8hpp_autotoc_md7}{}\doxysubsubsection{\texorpdfstring{Conventions}{Conventions}}\label{geography__utils_8hpp_autotoc_md7}

\begin{DoxyItemize}
\item All angles (lon/\+lat) are in {\bfseries{radians}}.
\item Great-\/circle distance returned by GCD /\+ GCD\+\_\+deriv is the {\bfseries{central angle}} (radians), i.\+e. arc length is {\ttfamily R \texorpdfstring{$\ast$}{*} angle}.
\end{DoxyItemize}\hypertarget{geography__utils_8hpp_autotoc_md8}{}\doxysubsubsection{\texorpdfstring{Error policy /\+ "{}don\textquotesingle{}t ruin the simulation"{}}{Error policy /\+ "{}don\textquotesingle{}t ruin the simulation"{}}}\label{geography__utils_8hpp_autotoc_md8}

\begin{DoxyItemize}
\item clamp() is used to keep floating-\/point roundoff from violating the domain constraints of trig inverse operations.
\item GCD\+\_\+deriv() does {\bfseries{not}} throw. If the derivative is mathematically undefined or numerically unstable because the two points are coincident (or nearly coincident), it returns:\+ \{ d, 0, 0 \} and emits a very cheap warning to std::\+cerr (at most once).
\end{DoxyItemize}\hypertarget{geography__utils_8hpp_autotoc_md9}{}\doxysubsubsection{\texorpdfstring{Optional warning control}{Optional warning control}}\label{geography__utils_8hpp_autotoc_md9}

\begin{DoxyItemize}
\item By default, one warning per process is printed the first time a degenerate derivative is detected.
\item Define {\ttfamily PARTICLE\+\_\+\+TRACKER\+\_\+\+GCD\+\_\+\+DERIV\+\_\+\+WARN=0} to disable all warnings.
\item Define {\ttfamily PARTICLE\+\_\+\+TRACKER\+\_\+\+GCD\+\_\+\+DERIV\+\_\+\+WARN\+\_\+\+ALWAYS=1} to warn every time (not recommended on HPC). 
\end{DoxyItemize}

The analytic expressions contain division by sin(d). When the two points coincide (or are extremely close), sin(d) -\/\texorpdfstring{$>$}{>} 0 and the derivatives are undefined /\+ numerically unstable.

Policy:\+

\item Return \{d, 0, 0\} (safe "{}no directional information"{} fallback).
\item Optionally print a warning to std::\+cerr:\+

\item disable:\+ PARTICLE\+\_\+\+TRACKER\+\_\+\+GCD\+\_\+\+DERIV\+\_\+\+WARN=0

\end{DoxyItemize}
\end{DoxyItemize}

Notes:\+
\begin{DoxyItemize}
\item These derivatives are for the central angle d, not arc length R\texorpdfstring{$\ast$}{*}d.
\item If you need derivatives of arc length, multiply dd\+\_\+dlon1 and dd\+\_\+dlat1 by Earth radius. 
\end{DoxyItemize}

Apply a local tangent-\/plane offset (x,y in meters) to a reference lon/\+lat (radians). 

This implements the spherical {\bfseries{azimuthal equidistant (AEQD)}} inverse transform centered at the reference point (lon,lat). The offset (x,y) is interpreted in the local tangent plane:\+
\begin{DoxyItemize}
\item x:\+ east (meters)
\item y:\+ north (meters)
\end{DoxyItemize}
