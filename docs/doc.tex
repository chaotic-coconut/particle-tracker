\section{Description}

Calculations consist of two parts:

\begin{enumerate}
\item preparation of the vector fields, which includes reading the data files and reconstruction of the smooth fields in space and time,
\item  simulation of advection of particles driven by the reconstructed fields. 
Particles are propagated with explicit Euler method. 
\end{enumerate}

\section{Interpolation of the Spatial Field}

In this section, we describe the interpolation of velocity fields obtained from HYCOM (for ocean currents) and Copernicus (for winds).
The data is stored as multidimensional tables in NCDF format.
We will not delve into the tedious process of reading the data files.
After preprocessing, we obtain rectangular grids of eastward and northward components of the velocity fields: $u_j (t)$ and $v_j (t)$.
The coordinates are degrees of latitude $\varphi$ and longitude $\lambda$.
Here, $j$ is the spatial index of the grid point.
The actual sorting does not matter because we build a kd-tree for nearest neighbor search.
%%In principle, the grid points can be scattered irregularly.
It is crucial that the positions of grid points remain constant over time.
We exclude grid points on land to improve simulation speed and save memory.
The variable $t$ represents time; it is discrete in the data but interpolated with cubic splines to achieve continuous dependence on time.

Simulating on large scales necessitates accounting for the Earth's curvature, because any flat projection introduces distortions in distances, angles, or areas, or all of these aspects together.
We utilize the fact that the Earth's surface is a smooth manifold and use local azimuthal equidistant projections for short-distance advection to minimize distortions.

The position of a particle, referred to as the query point, is used as the origin for local projections.
At any given time $t$, the query point $\left(\lambda,\varphi\right)$ is projected to minimize distortions in distances, calculated as Great Circle Distances (in radians):

\begin{equation}
s_j=\atan{\frac{|\bar{n}\times\bar{n}_j|}{\langle\bar{n}\cdot\bar{n}_j\rangle}}=
\atan{\frac{\sqrt{1-\left(\sin\varphi\sin\varphi_j+\cos\varphi\cos\varphi_j\cos(\lambda-\lambda_j)\right)^2}}{\sin\varphi\sin\varphi_j+\cos\varphi\cos\varphi_j\cos(\lambda-\lambda_j)}},
\end{equation}
where $s_j$ is the Great Circle Distance between the query point $\left(\lambda,\varphi\right)$ and a grid point $j$ with lat-lon coordinates $\left(\lambda_j,\varphi_j\right)$, $\bar{n}$ and $\bar{n}_j$ are normal unit vectors at these points. 
%%$|\bar{n}\times\bar{n}_j|$ and $\langle\bar{n}\cdot\bar{n}_j\rangle$ are the sine and cosine of $s_j$, which provide insight into deriving the equation.

We interpolate field values between grid points by calculating a weighted average of the values at the nearest grid points.
Weight functions decrease with the distance from the query point.
Nearest neighbors are searched on a kd-tree built at the start of the simulation.
The search radius is chosen such that $R \approx 1.5L$, where $L$ is the grid step, ensuring that there are at least $4$ grid points within the search radius for any typical query point position.

The weight function is defined as:
\begin{equation}
\mu(s_j)=\exp\left(-\frac{s_j^2}{L^2}\right),
\end{equation}
where $s_j$ is the distance from the query point to the grid point with index $j$. $L^2$ governs the shape of the Gaussian. Through trial and error, it is found that the shape must relate to the grid step $L$ for better approximation. If the query point coincides with the grid point, the weight is 1. Weights for grid points further away decrease smoothly with distance. The normalized weight - or a measure of grid point $j$ in the approximation is then
\begin{equation}
\rho_j=\frac{\mu(s_j)}{\sum_{s<R} \mu(s)},
\end{equation}
where the sum in the denominator is carried out for every grid point within the search radius.

The interpolated values of the eastward and northward components of the vector field are then
\begin{equation}
u(\lambda,\varphi,t)=\sum_{s_j<R} \rho_j u_j (t), \quad v(\lambda,\varphi,t)=\sum_{s_j<R} \rho_j v_j (t).
\end{equation}
